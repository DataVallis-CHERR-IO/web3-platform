# Logos

Converted from the official vector files (Cherrio_Logo_CMYK.pdf, Cherrio_Symbol_1.pdf) and recoloured to the digital palette. Each SVG is single-ink, so its ink is fixed in the file:

- `cherrio-wordmark-cherry.svg` — ink #ff0052. Default on `surface` (light) and `slate-900`.
- `cherrio-wordmark-white.svg` — ink #ffffff. On dark grounds, cherry-700 and cherry-900 fills.
- `cherrio-wordmark-ink.svg` — ink #090c0d. Single-colour print, stamps, on mist grounds when cherry is already used.
- `cherrio-wordmark-gradient.png` — the original raster with its vertical gradient. For social covers only, never in the UI (the UI has no gradients).
- `cherrio-symbol-cherry.svg` — ink #ff0052. Favicon, app icon, avatar placeholder.
- `cherrio-symbol-ink.svg` / `cherrio-symbol-white.svg` — single-ink symbol for light and dark grounds.
- `cherrio-symbol-gradient.svg` — the original gradient symbol from the print file. For print and social only.
