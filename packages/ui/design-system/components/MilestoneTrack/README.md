# MilestoneTrack

**Human layer.** How the money is released, as three steps: paid out = ink, donors reviewing = hatch, locked = raised surface, returned = deep cherry. Stacks vertically under 480px. Pair with the sentence: "Money is released in 3 steps, only after donors approve the receipts."

Consumer provides: `tranches` `[{label?, amount, state: 'released'|'voting'|'locked'|'rejected'}]`, `currency` (EUR default).
