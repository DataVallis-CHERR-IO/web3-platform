# ProofLink

**The bridge between layers.** Wherever the human layer makes a claim (money raised, paid out, approved), put one ProofLink next to it. It either scrolls to the page's proof section (`href="#proof"`, ↓) or opens the explorer (`external`, ↗).

- Default text: "Verified on blockchain". Alternatives: "See every donation", "See the payout".
- Never show the raw address or hash in its place.

Consumer provides: `href`, `external`, optional `children`.
